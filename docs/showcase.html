This document is the canonical demonstration of what the adoc processor can render. Every feature in the README's What works today section appears below, in roughly the order a reader is likely to meet them. The whole file is rendered with adoc docs/showcase.adoc and the result lives at docs/showcase.html.

1 Document header and metadata

The header above carries a title, two authors with email addresses, a revision line (v1.0.0, 2026-04-25: First public showcase), and a block of attribute entries. Attributes are referenced inline with curly braces — for example, you are reading version 0.1.0 of adoc, and the homepage is https://github.com/grahambrooks/adoc.

A :toc: attribute placed in the header pulls a Table of Contents above this introduction; :sectnums: numbers every heading; :sectanchors: adds a small hover anchor next to each heading so headings can be linked directly.

2 Paragraphs, line breaks, and inline quoting

Paragraphs are separated by blank lines. A trailing space-plus (` +`) at the end of a line forces a hard
break, so the second half of this sentence starts on its own line.

Inline quoting uses constrained pairs around a word — strong, emphasis, and monospace — or unconstrained pairs that work mid-word: bold, italic, mono. Combinations nest naturally: strong emphasis, bold mono. Specialchars are escaped automatically, so 1 < 2 && 3 > 2 survives as literal text without breaking the HTML.

Character replacements turn ©, ®, ™, …, — and → into typographic forms; arrows fire in both directions (←, ⇐, ⇒).

3 Inline extras: subscript, superscript, highlight, passthroughs, footnotes

Water is H2O, Einstein had E=mc2, and you can highlight a phrase inline with hashes (or with unconstrained pairs mid-word).

A constrained passthrough keeps *stars* and {attrs} literal, while the unconstrained **double stars** also survive verbatim. The ... macro emits raw HTML — Ctrl+C renders as keyboard keys.

Footnotes attach inline.footnote:[Here is an anonymous footnote with emphasis inside it.] You can also id a footnote so it can be referenced later: The AsciiDoc Language specification at https://docs.asciidoctor.org/asciidoc/latest/.

8 Source blocks with language

A [source,LANG] attribute on a listing emits a language-LANG class on the inner <code> element so downstream highlighters (Prism, Highlight.js, Rouge) can take over without conflict.

A Rust function with a language hint
fn main() {
    let greeting = "Hello, AsciiDoc!";
    println!("{}", greeting);
}
A Python snippet
def fizzbuzz(n: int) -> str:
    if n % 15 == 0:
        return "FizzBuzz"
    if n % 3 == 0:
        return "Fizz"
    if n % 5 == 0:
        return "Buzz"
    return str(n)
A Bash one-liner
adoc --emit-ast doc.adoc | jq '.blocks[0]' | adoc --from-ast -o filtered.html

12 Stdio extension model

The AST round-trips through serde_json, so external tools can post-process documents as a Unix-style pipeline:

# Render directly
adoc docs/showcase.adoc -o docs/showcase.html

# Or pipe through a custom filter
adoc --emit-ast docs/showcase.adoc \
    | jq '.blocks |= map(select(.kind != "comment"))' \
    | adoc --from-ast -o docs/showcase.html
